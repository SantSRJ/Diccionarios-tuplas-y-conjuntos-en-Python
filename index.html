    1.1Definición e inmutabilidad6 min

    Una lista que no se puede cambiar

    Una tupla es una secuencia ordenada e inmutable: una vez creada no se pueden agregar, quitar ni reemplazar elementos. Se indexa, se recorre y se corta (slicing) igual que una lista.

    Registros fijos

    Coordenadas (x, y), fechas, filas de datos.

    Varios retornos

    Una función puede devolver (minimo, maximo).

    Claves

    Al ser inmutables, pueden ser claves de diccionario.

    Como no cambian, solo tienen dos métodos: count() e index().

    Nota para el docente

    1.2Singleton y creación con tuple()5 min

    La coma hace la tupla, no los paréntesis

    Para Python, (5) es solo el número 5 entre paréntesis (como en (2 + 3) * 4). Una tupla de un elemento (singleton) necesita una coma: (5,). De hecho, los paréntesis son opcionales: t = 1, 2, 3 también es una tupla.

    La función tuple() convierte cualquier iterable (lista, string, rango) en tupla, y sin argumentos crea una tupla vacía.

    Alerta de error típico: el singleton sin coma

    colores = ("rojo") es un string, no una tupla. Al recorrerlo con for vas a obtener letra por letra: r, o, j, o. Escribí ("rojo",).

    x = (5)
y = (5,)                        # la coma es obligatoria
z = 5,                          # también es tupla (sin paréntesis)
print(type(x), type(y), type(z))   # int, tuple, tuple

colores = ("rojo")              # trampa: es un str
for c in colores:
    print(c, end=" ")           # r o j o
print()

vacia = ()                      # o tuple()
print(tuple([1, 2, 3]))         # (1, 2, 3) -> desde una lista
print(tuple("hola"))            # ('h', 'o', 'l', 'a') -> desde un string
print(tuple(range(3)))          # (0, 1, 2)
print(len(vacia), len(tuple())) # 0 0

    1.3Asignación múltiple, desempaquetado e intercambio7 min

    Desempaquetar: una variable por elemento

    Si a la izquierda del = hay varias variables separadas por comas, Python desempaqueta la secuencia de la derecha: el primer elemento va a la primera variable, el segundo a la segunda, y así. La cantidad tiene que coincidir.

    El intercambio a, b = b, a funciona porque primero se arma la tupla de la derecha (b, a) con los valores viejos y recién después se desempaqueta. No hace falta variable auxiliar.

    Con *resto una variable se queda con “todo lo que sobra” en forma de lista.

    Alerta de error típico: cantidad de variables distinta

    a, b = (1, 2, 3) lanza ValueError: too many values to unpack, y a, b, c = (1, 2) lanza not enough values to unpack. Lo vemos a fondo en el Módulo 4.

    # Asignación múltiple
a, b, c = 1, 2, 3
print(a, b, c)                    # 1 2 3

# Desempaquetar una tupla
alumno = ("Sofía", 21, "Sistemas")
nombre, edad, carrera = alumno
print(f"{nombre} tiene {edad} años y estudia {carrera}")

# Intercambio sin variable auxiliar
x, y = 10, 20
x, y = y, x                       # derecha: (20, 10) -> se desempaqueta
print(x, y)                       # 20 10

# Desempaquetar lo que devuelve una función
def extremos(valores):
    return min(valores), max(valores)
minimo, maximo = extremos([4, 1, 9, 7])
print(minimo, maximo)             # 1 9

# Desempaquetar dentro de un for
puntos = [(0, 0), (3, 4), (6, 8)]
for x, y in puntos:
    print(f"x={x} y={y}")

# El asterisco junta "el resto" en una lista
primero, *resto = [10, 20, 30, 40]
print(primero, resto)             # 10 [20, 30, 40]

    1.4Patrón DSU: Decorate, Sort, Undecorate7 min

    Ordenar por un criterio propio

    Las tuplas se comparan elemento a elemento, de izquierda a derecha: (2, "b") < (3, "a") porque 2 < 3; si el primero empata, decide el segundo. El patrón DSU aprovecha esto:

    Decorate

    Armar tuplas (criterio, dato).

    Sort

    Ordenar la lista de tuplas.

    Undecorate

    Quedarse solo con el dato.

    Es la base del “ranking de palabras más frecuentes” del Módulo 5. Hoy Python también ofrece sorted(lista, key=len), pero DSU muestra qué pasa por dentro y funciona con criterios combinados.

    Nota para el docente

    Escribí en el pizarrón las tres columnas (D, S, U) y llenalas a mano con 4 palabras antes de ejecutar. Remarcá el empate: con reverse=True, a igual largo, quedan en orden alfabético inverso.

    palabras = ["sol", "biblioteca", "mar", "python", "lista"]

# 1) DECORATE: tuplas (largo, palabra)
decorada = []
for p in palabras:
    decorada.append((len(p), p))
print(decorada)
# [(3, 'sol'), (10, 'biblioteca'), (3, 'mar'), (6, 'python'), (5, 'lista')]

# 2) SORT: se ordena por el largo; si empata, por la palabra
decorada.sort(reverse=True)
print(decorada)
# [(10, 'biblioteca'), (6, 'python'), (5, 'lista'), (3, 'sol'), (3, 'mar')]

# 3) UNDECORATE: nos quedamos con la palabra
ordenadas = []
for largo, p in decorada:
    ordenadas.append(p)
print(ordenadas)        # de la más larga a la más corta

# Las tuplas se comparan elemento por elemento
print((2, "b") < (3, "a"))    # True  -> decide el primer elemento
print((3, "a") < (3, "b"))    # True  -> empate en 3, decide el segundo

    2.1Pares clave-valor y búsqueda O(1)8 min

    ¿Por qué un diccionario busca tan rápido?

    Un diccionario guarda pares clave: valor. Por dentro es una tabla hash: Python aplica una función hash() a la clave y obtiene un número que indica en qué “casillero” guardar el valor. Para buscar, vuelve a calcular el hash y va directo a ese casillero.

    Lista: x in listaRevisa uno por uno: con n elementos, hasta n comparaciones. O(n)
    Diccionario: clave in dUn cálculo de hash y un salto: casi no depende de n. O(1)

    Simulador (simplificado, con 8 casilleros): escribí una fruta y buscala o agregala.

    Nota para el docente

    Con el simulador, buscá pera: un solo salto. Después contá cuántas comparaciones necesitaría una lista para encontrar la última fruta. Aclará que el hash real es otro (y más grande), pero la idea es la misma.

    precios = {"manzana": 1200, "pera": 1500, "banana": 900}

print(precios["pera"])          # 1500 -> acceso por CLAVE, no por posición
precios["kiwi"] = 2100          # agregar un par nuevo
precios["banana"] = 950         # misma clave: REEMPLAZA el valor
del precios["manzana"]          # eliminar un par
print(precios)                  # {'pera': 1500, 'banana': 950, 'kiwi': 2100}
print(len(precios))             # 3 pares

# 'in' pregunta por las CLAVES (en O(1))
print("kiwi" in precios)        # True
print(1500 in precios)          # False -> 1500 es un valor, no una clave

# Las claves son únicas: la última asignación gana
d = {"a": 1, "a": 2}
print(d)                        # {'a': 2}

    2.2Restricciones de claves: hashability6 min

    Solo lo inmutable puede ser clave

    Si una clave cambiara después de guardarla, su hash cambiaría y el diccionario la buscaría en otro casillero: se perdería. Por eso las claves deben ser hashables, es decir, inmutables: int, float, str, bool y tuplas (de elementos inmutables).

    Claves válidas"dni"42("Pérez", "Ana")
    Claves inválidas["Pérez", "Ana"]{"a": 1}(1, [2, 3])

    Las claves compuestas con tuplas son muy útiles: (apellido, nombre), (fila, columna), (sucursal, mes). Los valores, en cambio, pueden ser de cualquier tipo, incluso listas u otros diccionarios.

agenda = {}
agenda[("Pérez", "Ana")] = "11-5555-1234"
agenda[("Gómez", "Luis")] = "11-4444-9876"
print(agenda[("Pérez", "Ana")])

for (apellido, nombre), tel in agenda.items():
    print(f"{nombre} {apellido}: {tel}")

# Coordenadas como clave: un tablero "disperso"
tablero = {(0, 0): "X", (1, 1): "O"}
print(tablero.get((2, 2), "vacío"))     # vacío

# Los valores sí pueden ser mutables
materias = {"Ana": ["Álgebra", "Programación"]}
materias["Ana"].append("Física")
print(materias)

print(hash("hola") == hash("hola"))     # True: mismo dato, mismo hash
d = {}
d[["Pérez", "Ana"]] = "11-5555-1234"    # TypeError: unhashable type: 'list'

    2.4Patrón contador: histograma de frecuencias8 min

    Contar con un diccionario

    Es uno de los usos más frecuentes en análisis de datos: la clave es lo que se cuenta (una letra, una palabra, un usuario) y el valor es cuántas veces apareció.

    Versión largaif c in cont:    cont[c] += 1else:    cont[c] = 1
    Versión idiomáticacont[c] = cont.get(c, 0) + 1si no existe, arranca en 0
    Alerta de error típico: cont[c] += 1 sin inicializar

    La primera vez que aparece una clave, cont[c] += 1 intenta leer cont[c] antes de que exista: KeyError. Usá get(c, 0) o preguntá antes con in.

    Nota para el docente

    Ejecutá primero la versión larga y después la idiomática: el resultado es el mismo. Pedí que expliquen en voz alta qué devuelve cont.get(c, 0) la primera vez que aparece una letra.

    palabra = "banana"

# Versión explícita con if / in
cont = {}
for c in palabra:
    if c in cont:
        cont[c] += 1
    else:
        cont[c] = 1
print(cont)                        # {'b': 1, 'a': 3, 'n': 2}

# Versión idiomática con get
cont = {}
for c in palabra:
    cont[c] = cont.get(c, 0) + 1
print(cont)                        # {'b': 1, 'a': 3, 'n': 2}

# Histograma en texto, ordenado por letra
for letra, n in sorted(cont.items()):
    print(f"{letra} | {'*' * n} {n}")

# La más frecuente: recorrer items() buscando el máximo
mas, veces = None, 0
for letra, n in cont.items():
    if n > veces:
        mas, veces = letra, n
print(f"Más frecuente: '{mas}' ({veces} veces)")

    3.3Operaciones de conjuntos10 min

    Unión, intersección, diferencia y diferencia simétrica

    Tocá una operación para ver qué región del diagrama de Venn devuelve.

    Alerta de error típico: confundir - con ^

    A - B no es simétrica: son los elementos de A que no están en B, y A - B suele ser distinto de B - A. Si querés “los que están en uno solo de los dos”, es A ^ B.

    python = {"Ana", "Luis", "Sofía", "Tomás"}   # cursan Python
datos = {"Luis", "Tomás", "Valen", "Juli"}    # cursan Datos

print(sorted(python | datos))   # unión: los que cursan alguna
print(sorted(python & datos))   # intersección: cursan las dos -> ['Luis', 'Tomás']
print(sorted(python - datos))   # diferencia: solo Python -> ['Ana', 'Sofía']
print(sorted(datos - python))   # solo Datos -> ['Juli', 'Valen']
print(sorted(python ^ datos))   # simétrica: cursan UNA sola

# Equivalentes con métodos (aceptan listas como argumento)
print(sorted(python.union(["Pía"])))
print(sorted(python.intersection(["Ana", "Zoe"])))   # ['Ana']

# Comparaciones entre conjuntos
print({"Luis"} <= python)       # True -> subconjunto
print(python.isdisjoint({"Zoe"}))   # True -> no comparten nada
    Nota para el docente

    Pedí que, antes de tocar el diagrama, levanten la mano los que “cursan las dos”. Es la intersección hecha con personas: ayuda mucho a fijar & frente a |.

    4.2TypeError al modificar tuplas4 min

    Si necesitás cambiarla, creá otra

    Las tuplas no tienen append, remove ni asignación por índice. Si el dato tiene que cambiar, hay dos salidas: crear una tupla nueva (por concatenación o slicing) o convertir a lista, modificar y volver a tupla. Y si cambia seguido, quizás debía ser una lista desde el principio.

    Alerta de error típico: una tupla con una lista adentro

    t = (1, [2, 3]): la tupla es inmutable, pero la lista que contiene no. t[1].append(4) funciona y cambia el contenido, y además esa tupla no es hashable, así que no puede ser clave de diccionario.

    punto = (3, 5)

# Opción 1: construir una tupla NUEVA
punto = (10,) + punto[1:]      # (10, 5)
print(punto)

# Opción 2: lista -> modificar -> tupla
tmp = list(punto)
tmp.append(7)
punto = tuple(tmp)
print(punto)                   # (10, 5, 7)

# Trampa: la tupla no cambia, pero su lista interna sí
t = (1, [2, 3])
t[1].append(4)
print(t)                       # (1, [2, 3, 4])

punto.append(9)                # AttributeError: 'tuple' object has no attribute 'append'

    4.3Errores de desempaquetado5 min

    Contar antes de desempaquetar

    El desempaquetado exige que la cantidad de variables coincida con la cantidad de elementos. Si no, aparece un ValueError. Para depurarlo, imprimí len() y repr() del dato justo antes de la línea que falla.

    I2
    Intersecciones entre listas con conjuntos
     Intermedio
    
  
    Tenés los legajos inscriptos en dos materias (con repetidos por errores de carga). Informá: (1) cuántos alumnos distintos hay en cada materia, (2) quiénes cursan las dos, (3) quiénes cursan solo Programación, (4) el total de alumnos distintos entre ambas y (5) quiénes cursan exactamente una.
    Salida esperada
    Distintos en Programación: 5
Distintos en Bases: 5
Cursan las dos: [103, 105]
Solo Programación: [101, 102, 104]
Total distintos: 8
Exactamente una: [101, 102, 104, 106, 107, 108]
    
  
     Tu solución
    
  
    
  
     Ver pista
    Convertí cada lista con set(). Después: &, -, | y ^. Mostrá los resultados con sorted() para que tengan orden.
    
  
     Ver solución explicada
    1. p = set(programacion) y b = set(bases) eliminan los duplicados.
    2. len(p) y len(b) son los alumnos distintos.
    3. Intersección p & b; diferencia p - b; unión p | b; simétrica p ^ b.
    4. Sin conjuntos, la intersección exigiría un doble bucle O(n·m); con conjuntos, cada in es O(1).
    programacion = [101, 102, 103, 104, 102, 105, 101]
bases = [103, 105, 106, 107, 107, 108]

p = set(programacion)
b = set(bases)

print("Distintos en Programación:", len(p))      # 5
print("Distintos en Bases:", len(b))             # 5
print("Cursan las dos:", sorted(p & b))          # [103, 105]
print("Solo Programación:", sorted(p - b))       # [101, 102, 104]
print("Total distintos:", len(p | b))            # 8
print("Exactamente una:", sorted(p ^ b))
    

    

     Nivel avanzado: texto, puntuación y ranking con tuplas
    

    
  
    A1
    Palabras más frecuentes de un texto
     Avanzado
    
  
    Simulamos un archivo de texto con una cadena multilínea. Procesalo línea por línea: pasá a minúsculas, eliminá la puntuación con string.punctuation (y también ¿ y ¡, que no están incluidos), contá las palabras con un diccionario y mostrá el top 5 usando una lista de tuplas (frecuencia, palabra) ordenada de mayor a menor.
    
  
     Tu solución
    
  
    
  
     Ver pista
    linea.translate(str.maketrans("", "", signos)) borra todos los caracteres de signos de una vez. Para el ranking, aplicá DSU: armá (n, palabra), ordená con reverse=True y tomá [:5].
    
  
     Ver solución explicada
    1. Armá los signos a borrar: signos = string.punctuation + "¿¡".
    2. Creá la tabla de traducción una sola vez: tabla = str.maketrans("", "", signos).
    3. Para cada línea de texto.splitlines(): linea.lower().translate(tabla).split().
    4. Contá con el patrón get(p, 0) + 1.
    5. Decorate: lista de tuplas (n, p) desde items(). Sort: sort(reverse=True). Undecorate: imprimir las 5 primeras desempaquetando for n, p in ranking[:5].

    import string

texto = """Python es un lenguaje claro; Python es potente.
¿Por qué aprender Python? Porque Python se lee fácil,
y porque los diccionarios, las tuplas y los conjuntos
resuelven problemas reales: contar, ordenar y comparar.
¡Contar palabras es el primer paso del análisis de texto!"""

signos = string.punctuation + "¿¡"            # ¿ y ¡ no vienen incluidos
tabla = str.maketrans("", "", signos)        # tabla que BORRA esos signos

conteo = {}
for linea in texto.splitlines():             # como si leyéramos un archivo
    limpia = linea.lower().translate(tabla)
    for p in limpia.split():
        conteo[p] = conteo.get(p, 0) + 1

# DSU: (frecuencia, palabra) para ordenar por frecuencia
ranking = []
for palabra, n in conteo.items():
    ranking.append((n, palabra))
ranking.sort(reverse=True)

print("Palabras distintas:", len(conteo))
for n, palabra in ranking[:5]:
    print(f"{palabra:<10} {n}")
